# 05 · Sistemas No Lineales
Método 05

Newton para Sistemas
No Lineales

Extensión multivariable del método de Newton-Raphson. Resuelve sistemas de ecuaciones no lineales usando la matriz Jacobiana y el método de eliminación de Gauss en cada iteración.

Sistemas · No Lineales Matriz Jacobiana

Fundamentos Teóricos

1. Formulación del Problema

Dado un sistema de n ecuaciones no lineales con n incógnitas, se busca el vector x = [x₁, x₂, ..., xₙ]ᵀ que satisfaga simultáneamente todas las ecuaciones:

Sistema de ecuaciones no lineales
F(x) = 0, donde F: ℝⁿ → ℝⁿ

2. La Matriz Jacobiana

La generalización multivariable de la derivada es la matriz Jacobiana J(x), cuyos elementos son todas las derivadas parciales de cada función respecto a cada variable:

Elemento (i,j) de la Jacobiana
J_ij = ∂fᵢ / ∂xⱼ

3. Fórmula Iterativa

En cada iteración se resuelve el sistema lineal J(xₙ)·Δx = −F(xₙ) y se actualiza el vector solución:

Actualización del vector solución
x_(n+1) = xₙ + Δx, donde J(xₙ)·Δx = −F(xₙ)

Seleccionar el vector inicial x⁰ = [x₁⁰, x₂⁰, ..., xₙ⁰]ᵀ.

Evaluar el vector F(xₙ) y construir la matriz Jacobiana J(xₙ).

Resolver el sistema lineal J(xₙ)·Δx = −F(xₙ) (por eliminación de Gauss).

Actualizar: x_(n+1) = xₙ + Δx.

Evaluar la norma ‖Δx‖ o ‖F(x_(n+1))‖. Si es menor que la tolerancia, detener.

Si no, repetir desde el paso 2 con el nuevo xₙ.

4. Criterio de Convergencia

Norma euclidiana del error
‖Δx‖₂ = √(Δx₁² + Δx₂² + ... + Δxₙ²) < ε
