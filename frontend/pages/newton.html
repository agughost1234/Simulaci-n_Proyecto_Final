# 04 · Raíces Abiertas
Método 04

Método de
Newton-Raphson

Método abierto de búsqueda de raíces. Usa la tangente a la curva en el punto actual para estimar la siguiente aproximación. Convergencia cuadrática cuando converge.

Raíces · Método Abierto Convergencia cuadrática

Fundamentos Teóricos

1. Interpretación Geométrica

A partir de un punto inicial x₀, se traza la tangente a la curva f(x) en ese punto. La intersección de esa tangente con el eje x define la siguiente aproximación x₁. El proceso se repite iterativamente.

2. Deducción de la Fórmula Iterativa

La ecuación de la tangente a f en xₙ es: y − f(xₙ) = f'(xₙ)(x − xₙ). Fijando y = 0 y despejando x se obtiene la fórmula de iteración:

Fórmula iterativa de Newton-Raphson
x_(n+1) = xₙ − f(xₙ) / f'(xₙ)

Seleccionar un punto inicial x₀ cercano a la raíz.

Evaluar f(xₙ) y f'(xₙ). Verificar que f'(xₙ) ≠ 0.

Calcular la nueva aproximación: x_(n+1) = xₙ − f(xₙ)/f'(xₙ).

Calcular el error relativo: |x_(n+1) − xₙ| / |x_(n+1)|.

Si el error < tolerancia, detener. Si no, repetir desde el paso 2 con xₙ = x_(n+1).

3. Orden de Convergencia

El método de Newton-Raphson tiene convergencia cuadrática cuando la raíz es simple, lo que significa que el número de dígitos correctos se duplica en cada iteración.

Error en la iteración n+1 (raíz simple)
eₙ₊₁ ≈ [f''(ξ) / (2·f'(xₙ))] · eₙ²

4. Criterios de Paro

  • Error absoluto: |x_(n+1) − xₙ| < ε
  • Error relativo: |x_(n+1) − xₙ| / |x_(n+1)| < ε
  • Valor de función: |f(x_(n+1))| < ε

5. Casos de No Convergencia

  • Si f'(xₙ) = 0, el método falla (división por cero).
  • Si el punto inicial está muy lejos de la raíz, puede diverger o oscilar.
  • Raíces múltiples reducen el orden de convergencia a lineal.
