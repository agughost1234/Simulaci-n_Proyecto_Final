# 03 · Raíces Cerradas
Método 03

Método de
Bisección

Método cerrado de búsqueda de raíces. Divide repetidamente un intervalo [a,b] donde hay cambio de signo, garantizando convergencia siempre que f(a)·f(b) < 0.

Raíces · Método Cerrado Convergencia garantizada

Fundamentos Teóricos

1. Principio del Cambio de Signo (Teorema de Bolzano)

Si f es una función continua en [a, b] y f(a)·f(b) < 0, entonces existe al menos un valor c ∈ (a, b) tal que f(c) = 0. Este es el fundamento matemático del método.

2. Descripción del Algoritmo

En cada iteración se calcula el punto medio del intervalo. Según el signo de f en ese punto, el intervalo se reduce a la mitad que contiene la raíz. La convergencia es lineal y garantizada.

Punto medio (iteración k)
c = (a + b) / 2

Verificar que f(a)·f(b) < 0 (existe cambio de signo en el intervalo).

Calcular el punto medio: c = (a + b) / 2.

Evaluar f(c). Si f(c) = 0, c es la raíz exacta. Fin.

Si f(a)·f(c) < 0, la raíz está en [a, c]. Actualizar b = c.

Si f(c)·f(b) < 0, la raíz está en [c, b]. Actualizar a = c.

Repetir desde el paso 2 hasta que |b − a| < tolerancia o f(c) ≈ 0.

3. Estimación del Error

Error máximo en la iteración n
|error| ≤ (b − a) / 2ⁿ

El número mínimo de iteraciones n para alcanzar una tolerancia ε se puede estimar como:

Número mínimo de iteraciones
n ≥ log₂((b − a) / ε)

4. Ventajas y Limitaciones

  • Ventaja: Siempre converge si la condición inicial se cumple.
  • Ventaja: El error es predecible y acotable de antemano.
  • Limitación: Convergencia lenta (lineal) comparada con métodos abiertos.
  • Limitación: Solo encuentra una raíz por intervalo y no funciona con raíces múltiples de multiplicidad par.
