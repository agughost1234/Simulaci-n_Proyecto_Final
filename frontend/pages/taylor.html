Método 01

Polinomios de Taylor
y el Resto

Aproximación de funciones diferenciables mediante una suma finita de derivadas evaluadas en un punto, con estimación del error mediante el término del resto.

Series · Aproximación Sumatorias y Derivadas

Fundamentos Teóricos

1. Definición del Polinomio de Taylor

Sea f una función (n+1)-veces diferenciable en un intervalo que contiene al punto a. El polinomio de Taylor de grado n alrededor de a es la mejor aproximación polinómica de grado n a f en la vecindad de ese punto.

Fórmula General — Polinomio de Taylor de grado n
P_n(x) = Σ [f⁽ᵏ⁾(a) / k!] · (x − a)ᵏ, k = 0, 1, ..., n

2. Serie de Maclaurin

Cuando el punto de expansión es a = 0, el polinomio de Taylor se denomina Serie de Maclaurin. Es la forma más común utilizada en análisis numérico para funciones elementales como ex, sin(x) y cos(x).

Caso particular: Serie de Maclaurin (a = 0)
P_n(x) = f(0) + f'(0)·x + f''(0)·x²/2! + f'''(0)·x³/3! + ...

3. El Resto de Taylor (Término de Error)

El polinomio de Taylor no es la función exacta; existe un error llamado Resto de Lagrange. Este término cuantifica la diferencia entre la función real y su aproximación polinómica.

Resto de Lagrange
Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ) / (n+1)! · (x − a)ⁿ⁺¹, ξ ∈ (a, x)

4. Algoritmo de Evaluación

Seleccionar la función f(x), el punto de expansión a y el grado n.

Calcular las derivadas sucesivas f'(a), f''(a), ..., f⁽ⁿ⁾(a).

Dividir cada derivada entre el factorial correspondiente: f⁽ᵏ⁾(a) / k!

Multiplicar cada coeficiente por la potencia (x − a)ᵏ.

Sumar todos los términos para obtener P_n(x).

Estimar el error máximo con el Resto de Lagrange.
