Método 02

Cambio de Base
Numérica

Algoritmo de divisiones y multiplicaciones sucesivas para representar un número decimal en cualquier base posicional b ≥ 2, con demostración basada en el Teorema Fundamental de la Numeración.

Sistemas Posicionales Divisiones Sucesivas

Fundamentos Teóricos

1. Introducción a los Sistemas de Numeración

Un sistema de numeración es un conjunto de símbolos y reglas que permiten construir todos los números válidos. Todo sistema de numeración moderno es posicional: el valor de un dígito depende no solo de su símbolo, sino de la posición que ocupa dentro del número.

Históricamente se adoptó el sistema decimal (base 10) por la anatomía humana. En computación predomina el sistema binario (base 2) por la naturaleza biestable de los circuitos lógicos.

2. Teorema Fundamental de la Numeración

Cualquier número real positivo N puede expresarse de forma única en un sistema posicional de base b (con b ≥ 2 entero) mediante una sucesión polinómica de potencias de la base.

Representación en base b
N = (dₙ dₙ₋₁ ... d₁ d₀ . d₋₁ d₋₂ ... d₋ₘ)_b, donde 0 ≤ dᵢ < b
Valor decimal equivalente — Suma ponderada
N₁₀ = Σ dᵢ · bⁱ, i = −m, ..., n

3. Algoritmo para la Parte Entera (Divisiones Sucesivas)

Para convertir la parte entera de un número decimal a la base b, se aplica repetidamente el algoritmo de la división de Euclides. Cada residuo obtenido es un dígito de la representación en base b, leídos en orden inverso.

Paso general del algoritmo (paso k)
Q_(k-1) = b · Qₖ + R_(k-1) → R_(k-1) = d_(k-1)

Dividir N entre la base b. El residuo R₀ es el dígito menos significativo d₀.

Tomar el cociente Q₁ y volver a dividir entre b. El nuevo residuo R₁ = d₁.

Repetir hasta que el cociente sea cero.

Leer los residuos en orden inverso: el último es el dígito más significativo.

4. Algoritmo para la Parte Fraccionaria (Multiplicaciones Sucesivas)

Para un número estrictamente fraccionario F (0 < F < 1), se multiplica repetidamente por la base b. La parte entera de cada producto es el siguiente dígito fraccionario.

Paso general (posición fraccionaria k)
F_(k-1) · b = d_(-k) + Fₖ → d_(-k) = Parte entera de (F_(k-1) · b)

Multiplicar la parte fraccionaria F por la base b.

La parte entera del resultado es el dígito d₋₁.

Tomar la parte fraccionaria sobrante y repetir el proceso.

Terminar cuando la fracción sea cero (exacto) o al detectar un ciclo (periódico).

5. Ejemplo: Conversión de 22.625₁₀ a Base 2

Parte entera (22): 22÷2=11 R0 → 11÷2=5 R1 → 5÷2=2 R1 → 2÷2=1 R0 → 1÷2=0 R1. Resultado: 10110₂

Parte fraccionaria (0.625): 0.625×2=1.250 → 0.250×2=0.500 → 0.500×2=1.000. Resultado: 0.101₂

Resultado final
22.625₁₀ = 10110.101₂

6. Limitaciones — Representaciones Periódicas

El algoritmo fraccionario no siempre es finito. Una fracción exacta en base 10 puede transformarse en una serie infinita periódica en otra base si los denominadores no comparten factores primos con la base destino. Por ejemplo, 22.625₁₀ en base 3 produce 211.12̄₃ (periódico).
