# 06 · Interpolación
Método 06

Polinomio Interpolante
de Lagrange

Construye un único polinomio de grado n que pasa exactamente por n+1 puntos dados, utilizando los polinomios base de Lagrange como funciones de peso.

Interpolación Polinomial Polinomios base

Fundamentos Teóricos

1. El Problema de Interpolación

Dado un conjunto de n+1 puntos distintos (x₀,y₀), (x₁,y₁), ..., (xₙ,yₙ), existe un único polinomio P(x) de grado ≤ n que pasa por todos ellos. El método de Lagrange construye este polinomio de forma explícita.

2. Polinomios Base de Lagrange

Para cada punto xᵢ se construye un polinomio base Lᵢ(x) que vale 1 en xᵢ y 0 en todos los demás puntos de interpolación.

Polinomio base i-ésimo
Lᵢ(x) = Π [(x − xⱼ) / (xᵢ − xⱼ)], j = 0,...,n, j ≠ i

3. El Polinomio Interpolante

El polinomio interpolante de Lagrange es la combinación lineal de los polinomios base, ponderada por los valores y de cada punto:

Polinomio interpolante de Lagrange
P(x) = Σ yᵢ · Lᵢ(x), i = 0, 1, ..., n

Ingresar los n+1 puntos: (x₀,y₀), (x₁,y₁), ..., (xₙ,yₙ).

Para cada i, calcular el polinomio base Lᵢ(x).

Multiplicar cada Lᵢ(x) por su correspondiente yᵢ.

Sumar todos los términos para obtener P(x).

Evaluar P(x) en el punto deseado x*.

4. Error de Interpolación

Error de interpolación de Lagrange
E(x) = f⁽ⁿ⁺¹⁾(ξ) / (n+1)! · Π (x − xᵢ), ξ ∈ (min xᵢ, max xᵢ)

5. Propiedad de Unicidad

El polinomio interpolante de grado n que pasa por n+1 puntos distintos es único. Diferentes métodos de interpolación (Lagrange, Newton, Hermite) construyen el mismo polinomio, solo con representaciones algebraicas distintas.
