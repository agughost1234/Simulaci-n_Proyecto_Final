# 08 · Ajuste de Curvas
Método 08

Método de
Mínimos Cuadrados

Ajusta un modelo matemático a un conjunto de datos experimentales minimizando la suma de los cuadrados de los residuos entre los valores observados y los predichos por el modelo.

Ajuste · Regresión Minimización de error

Fundamentos Teóricos

1. El Problema de Ajuste de Curvas

A diferencia de la interpolación, el ajuste de curvas no exige que el modelo pase exactamente por todos los puntos. En cambio, busca el modelo que mejor representa la tendencia general de los datos, minimizando el error total.

2. Criterio de Mínimos Cuadrados

Dado un conjunto de n datos (xᵢ, yᵢ) y un modelo y = f(x; a₀, a₁, ..., aₘ), se define el residuo de cada punto como la diferencia entre el valor observado y el predicho. El criterio de mínimos cuadrados minimiza la suma de los cuadrados de todos los residuos:

Función a minimizar
S = Σ [yᵢ − f(xᵢ)]², i = 1, ..., n

3. Regresión Lineal Simple (y = a₀ + a₁x)

Para el caso más común del modelo lineal, las condiciones de mínimo (derivadas parciales igualadas a cero) producen el sistema de ecuaciones normales:

Ecuaciones normales — Regresión lineal
a₁ = [n·Σ(xᵢyᵢ) − Σxᵢ·Σyᵢ] / [n·Σxᵢ² − (Σxᵢ)²]
a₀ = (Σyᵢ − a₁·Σxᵢ) / n = ȳ − a₁·x̄

4. Regresión Polinómica (grado m)

Para un polinomio de grado m, el sistema de ecuaciones normales tiene dimensión (m+1)×(m+1) y se resuelve por métodos de álgebra lineal como eliminación de Gauss o descomposición LU:

Sistema de ecuaciones normales (forma matricial)
AᵀA · c = Aᵀy

Ingresar los datos (xᵢ, yᵢ) y seleccionar el tipo de modelo.

Calcular las sumas necesarias: Σxᵢ, Σyᵢ, Σxᵢ², Σxᵢyᵢ, etc.

Plantear y resolver el sistema de ecuaciones normales.

Obtener los coeficientes del modelo a₀, a₁, ..., aₘ.

Calcular el coeficiente de determinación R² para evaluar la calidad del ajuste.

5. Coeficiente de Determinación R²

R² mide qué proporción de la variabilidad total de los datos es explicada por el modelo. Su valor está entre 0 y 1; un R² cercano a 1 indica un excelente ajuste.

Coeficiente de determinación
R² = 1 − (S_res / S_tot), donde S_tot = Σ(yᵢ − ȳ)²

6. Modelos No Lineales Linealizables

Algunos modelos no lineales pueden ser transformados a forma lineal mediante cambios de variable, permitiendo aplicar las ecuaciones normales del caso lineal. Ejemplos comunes:

  • Exponencial: y = ae^(bx) → ln(y) = ln(a) + bx
  • Potencial: y = axᵇ → log(y) = log(a) + b·log(x)
  • Saturation: y = ax / (b+x) → 1/y = b/(a·x) + 1/a
