Proyecto final - metodos numericos

Este proyecto contiene implementaciones separadas en Python de:

1. Metodo de Newton para sistemas no lineales.
2. Polinomio interpolante de Lagrange.
3. Diferencias divididas de Newton.

Los modulos estan pensados para ser reutilizados desde una interfaz grafica o una calculadora, con funciones puras, validacion de datos y resultados faciles de consumir.

Archivos principales:

- metodos/newton_sistemas.py
- metodos/lagrange.py
- metodos/newton_interpolacion.py
- metodos/__init__.py
- ejemplos.py

Instalacion:

pip install -r requirements.txt

Uso rapido:

python ejemplos.py
